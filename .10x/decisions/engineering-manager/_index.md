# Engineering Manager — Princípios e features ativas

## Princípios
- Tarefas de no máximo meio dia, cada uma com critério de pronto verificável.
- Os portões de qualidade (conferência, isolamento entre casas, auditoria) não são negociáveis por prazo.
- Primeiro a base e a segurança, depois o fluxo de medicação, depois alertas e gestão.
- Mostrar algo funcionando ao usuário ao fim de cada marco.
