# Product Manager — Princípios e features ativas

## Princípios
- Entregar primeiro o módulo de maior risco e valor (medicação) e validar com uma casa-piloto.
- O tempo por registro no tablet é requisito de produto, não detalhe.
- O sistema não prescreve: registra e confere o que foi prescrito.
- Família recebe resumo aprovado, não dados clínicos brutos.
